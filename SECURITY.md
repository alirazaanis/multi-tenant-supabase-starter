# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately via [GitHub Security Advisories](https://github.com/alirazaanis/multi-tenant-supabase-starter/security/advisories/new).

Include:

- A description of the issue and potential impact
- Steps to reproduce
- Affected paths or components (e.g. API route, migration, RLS policy)

We aim to acknowledge reports within a few business days.

## Scope

**Multi-Tenant Supabase Starter** is a reference implementation. Production deployments require review of auth flows, RLS policies, rate limits, and secret handling.
