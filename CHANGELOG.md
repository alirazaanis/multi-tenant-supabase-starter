All notable changes to this project are documented in this file.

## [1.0.0] - 2026-06-05

### Added

- **Multi-Tenant Supabase Starter** — platform owner console and per-org customer sites with internal email mapping
- Internal email mapping for same-email customers across orgs
- SQL migration with RLS, RPCs, and auth trigger
- Next.js App Router app with hub + tenant routes
- Unit tests (Vitest) and smoke E2E tests (Playwright)
- CI workflow, Dependabot, and contributor docs
